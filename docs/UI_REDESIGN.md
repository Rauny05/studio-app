# UI redesign

## System

- Light theme by default (warm paper `#fbfaf9`, ink `#1a1917`), separate dark theme with its own tokens. Geist / Geist Mono.
- Hairline borders, 5–8px radii, shadows only on overlays and hovered launcher cards, no gradients or glass.
- Neutral grey for selection; lime only for checkboxes, focus and the “now” marker.
- Shared primitives: section heading (`.cc-hs`), workspace view (`.cc-view`: toolbar with underline tabs → full-bleed content → docked detail panel), rows (`.cc-item`, `.cc-row`), property-list detail fields, launcher cards.

## Shell

Workspace menu (theme, sync status, collapse, sign out) · search with ⌘K · core nav · Studio (Operations, Deliverables, Scripts, Studio AI) · Apps (pinned, else recent, plus All apps) · footer icons (App health, Integrations, Settings). Header: breadcrumb, the hosted app’s name/status/reload/fullscreen/switcher, New, notifications.

## Home

Full width, three columns at ≥1500px (Today + This week | To Shoot + Email | AI briefing, Studio figures, Recent apps, Activity), two columns down to 1100px, one column on mobile. One data-built summary sentence; connection problems are one-line notes, not banners. AI briefing runs only on request and only with the data consented to in Studio AI.

## Application library

Launcher, not a table: Pinned, Recently opened, then sections by purpose (Productivity, Finance, Operations, Content and Media, File Management, Utilities). Each card: icon, name, accurate description, health, last opened, pin. The whole card opens the internal route. “Integration status” tab is the admin view, including every excluded project and why.

## Tasks / My Day, To Shoot, Inbox

Toolbar + full-bleed lists + detail panel docked right only while something is selected (full-screen sheet on mobile). Detail panels are property lists. To Shoot board has stage dots and short dashed empty columns; Inbox is single-line rows.
